# Godmode Bot

## Pull requests

- Push trivial changes (typos, copy, config tweaks, small one-file fixes) straight to `main`; open a PR for everything else.
- PR descriptions: 2–3 short bullets saying what changed and why. Nothing else — no headings, test plans, screenshots sections or summaries. The title carries the weight.

## Chat look and behavior

- Don't change how chats look or behave for everyone. Add a new style as an option in Settings → General → Chat (`useUi` in `apps/desktop/src/stores/ui.ts`, per computer) and keep the current one as the default.
